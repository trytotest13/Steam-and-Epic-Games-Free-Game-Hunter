Custom sites (beta scanner rules)

Teach the hunter other stores (GOG, itch.io, Humble, …). Each rule tells the generic scanner how to find free game cards and their buttons on one site. Any selector you leave empty falls back to the built-in heuristics. Test with Dry run in the popup — the found buttons get highlighted instead of clicked.

How to find selectors

  1. Right-click a game card on the store → Inspect.
  2. Find the element that wraps one whole card and note a CSS selector for it (e.g. .product-card).
  3. Do the same for the title, the price and the "Add to cart" button inside the card.
  4. Save, open the store, click the extension icon → Scan, and check the dry-run highlights.
